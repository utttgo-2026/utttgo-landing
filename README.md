# UTTT-GO Landing Page

Landing Page oficial del proyecto académico **UTTT-GO**, desarrollado para la comunidad de la Universidad Tecnológica de Tula-Tepeji.

## Descripción

UTTT-GO es una aplicación móvil orientada a facilitar la compra y venta de alimentos dentro del campus UTTT.

La aplicación permite a los compradores:

- Buscar alimentos.
- Consultar categorías.
- Aplicar filtros.
- Comparar opciones de vendedores.
- Consultar precios y calificaciones.
- Realizar pedidos directos.
- Indicar un punto de referencia para la entrega.
- Agregar observaciones.
- Dar seguimiento a sus pedidos.
- Comunicarse mediante chat.
- Recibir notificaciones.
- Confirmar entregas mediante código QR.
- Calificar al vendedor después de una entrega.

Los vendedores pueden:

- Activar su perfil de vendedor.
- Publicar alimentos.
- Editar sus publicaciones.
- Administrar precio y disponibilidad.
- Recibir pedidos.
- Aceptar o rechazar pedidos.
- Actualizar estados.
- Comunicarse con compradores.
- Validar entregas.
- Consultar historial de ventas.

## Pago

UTTT-GO utiliza únicamente pago en efectivo al momento de recibir el pedido.

La aplicación no procesa pagos electrónicos.

## Tecnologías de la Landing Page

- HTML5
- CSS3
- GitHub Pages

No se utiliza JavaScript.
